重启 DSH？

ToolHub 检测到 DSH 已在运行。重启后由 ToolHub 获取新的浏览器认证链接；当前 DSH 网页会断开，正在执行的 Agent 任务可能中断。

状态与操作

  • 运行状态：按 DSH Web 进程与端口检测，不要求 ToolHub 曾经启动它。
  • 启动：没运行时启动单实例；已经运行时不重复启动。
  • 暂停：停止全局检测到的 DSH Web 实例。
  • 重启：重启当前唯一实例，刷新认证链接。
  • 打开：通过 Windows 默认浏览器打开 DSH。
