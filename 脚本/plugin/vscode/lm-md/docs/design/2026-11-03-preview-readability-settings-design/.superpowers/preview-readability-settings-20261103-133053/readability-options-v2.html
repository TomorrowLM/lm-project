LangChain Agent 的调试流程

调试时先确认 Agent 是否调用了预期工具，再检查工具参数、返回结果和最终回答。按这个顺序查看，能更快缩小问题范围。

阅读提示　标题层级清晰；正文保持舒适行宽；长表格与代码块在自己的区域滚动。

常用事件

事件会记录链、模型、检索器和工具的执行阶段。表格标题固定在顶部，横向内容不会挤压整篇正文。

  • 预设 25%、50%、75%、100%，也可输入自定义百分比。
  • 保持图片宽高比例；修改持久写入 Markdown，可撤销。

上传操作

  • 复用 D:/LM/lm-project/脚本/plugin/upload_cos/ 的既有上传器与目录规则。
  • 本地图片直接上传；外链图片先下载临时副本；成功后替换源地址并保留 alt/尺寸。

1 · 设置按钮放在哪里

选一个入口。设置项会自动保存，并在 Markdown 预览重新打开后恢复。

A
推荐

预览工具栏右上角齿轮

紧邻“同步到 Copilot”。点击打开轻量面板，不离开当前文档，最容易发现和调整。

B

居中设置窗口

可容纳更多选项，但会遮住正文；每次微调字号都要关闭窗口查看效果。

C

只放在 VS Code 设置页

符合原生设置习惯、长期配置更清楚；阅读时不容易快速找到，也无法即时对照正文。

2 · Mermaid 大图如何完整查看

A

整张图自动缩到当前区域

一眼能看到全图；图很宽或很高时，文字会缩得很小。

B
推荐

适配宽度，提供缩放和平移

初始保持可读字号；宽图可横向滚动，缩放、适应和重置控制保证边缘内容可查看。

3 · Markdown 正文排版密度

A

紧凑

14 px、较小段间距；适合高密度技术笔记，长时间阅读容易疲劳。

B
推荐

舒适阅读

16 px、行距约 1.75；正文控制行长，表格和代码保持可用宽度并单独滚动。

C

宽松阅读

18 px、较窄正文栏和更大留白；读起来轻松，但一屏显示内容较少。

推荐排版会做的调整

  • 标题字号、粗细和段前段后间距形成明确层级。
  • 正文行宽适中，段落、列表与引用区分更清楚。
  • 代码块、表格、引用块使用低对比度背景和一致边框。

保持内容完整

  • 正文区域继续使用可用编辑器宽度。
  • 宽表格和长代码在自己的容器里滚动，不挤压整页。
  • 字号、行距、宽度和主题可随时调节并持久保存。
