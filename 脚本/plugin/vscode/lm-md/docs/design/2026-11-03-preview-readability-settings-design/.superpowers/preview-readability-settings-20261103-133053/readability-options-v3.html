图片右键菜单

右键预览图片可设置显示宽度：25%、50%、75%、100% 或自定义百分比。保持宽高比，保留 alt 和现有属性，并把变更写回 Markdown，支持撤销。

  • 上传固定使用腾讯 COS；本地图片直接上传，外链图片先下载临时副本。
  • 上传成功后替换 Markdown 图片地址，保留 alt 和尺寸；上传失败不改源文档。
  • 用户在设置里配置自己的 SecretId、SecretKey、Bucket、Region 与目录前缀。
