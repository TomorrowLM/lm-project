事件流与调试

通过回调事件观察模型、链、检索器和工具的执行过程，并在目录中快速定位章节。

回调事件

每个事件对应一个运行阶段。下面的宽表格在自身区域滚动，不会覆盖左侧目录。

目录定位反馈

点击左侧“事件流与调试”后，当前预览滚动到此章节；活动目录项同步高亮。编辑器标签保持不变。

这版解决的点

  • 目录独占侧栏高度，长目录有自己的滚动区域。
  • 文档名和路径提示目录当前跟随的预览。
  • 正文不再预留目录栏宽度，长表格只在表格内部横向滚动。

需要你确认的使用感受

  • 左侧 Activity Bar 会多一个 Markdown 图标。
  • 需要切换到该图标，才能查看目录；关闭侧栏时正文仍铺满编辑器。
  • 切换 Markdown 预览标签时，侧栏自动切换对应目录。
