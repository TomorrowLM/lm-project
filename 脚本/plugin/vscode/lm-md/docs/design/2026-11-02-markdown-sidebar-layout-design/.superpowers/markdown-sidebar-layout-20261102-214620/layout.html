B · 独立 Markdown 侧栏

在 Activity Bar 增加独立入口，打开后整栏用于目录、标题搜索和折叠操作；Explorer 文件树保持原样。适合长目录和频繁定位。

两种布局共用的行为

  • 正文只占编辑器区域；目录移至 VS Code 侧栏，不覆盖预览内容。
  • 点击目录标题后，在当前 Markdown 预览标签中定位并短暂高亮，不额外打开标签。
  • 目录跟随当前激活的 Markdown 预览；没有活动预览时显示空状态提示。
  • 长表格、代码块和 Mermaid 图表超出宽度时在内容块内滚动。
