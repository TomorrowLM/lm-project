# 技能改进器

技能改进器面向工作区中的 `SKILL.md` 文件。它会把技能正文和你提供的改进目标、执行结果或失败案例交给 DSH 已配置的模型，生成一份供审阅的完整新稿。它不读取或推断未提供的任务历史。

## 使用流程

1. 调用 `skill_refiner_prepare`，传入相对工作区根目录的 `SKILL.md` 路径，以及改进目标和可选任务证据。
2. 审阅返回的建议正文。
3. 你明确决定应用时，调用 `skill_refiner_apply` 并传入提案 ID。工具会检查原文件未在生成提案后发生变化，再保存快照并更新文件。
4. 用 `skill_refiner_history` 查看快照；用 `skill_refiner_rollback` 按快照 ID 恢复先前版本。

## 边界

- 只接受当前工作区内名为 `SKILL.md` 的文件，不接受绝对路径或指向工作区外的符号链接。
- 文件默认最大 64 KiB，送入模型的补充证据最多 5000 字符。
- 生成提案不会改写技能。应用和回滚是单独操作。
- 版本快照保存在工作区 `.dsh-skill-refiner/history/`，内含技能正文；请按项目数据管理要求保护或排除此目录。
- 提案暂存在当前插件进程内存中。插件重载或 DSH 进程重启后，未应用的提案会失效；已保存的快照仍可用于回滚。
- 模型接收技能正文和所提供的证据。发送前请检查其中是否包含不应提交给所选模型提供方的内容。
