C. 焦点预览

选中图片立即展示大图和详情；预览更醒目，但批量浏览效率略低。

点击任一方案即可记录选择。也可以在终端回复 A / B / C；我推荐 A，它能最自然地融入当前画廊，并将放大预览放在卡片点击后的独立窗口中。
