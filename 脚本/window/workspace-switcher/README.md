# WorkspaceSwitcher

WorkspaceSwitcher 是一个 Windows 桌面工作区管理工具：把当前打开的应用窗口归类到多个工作区，在工作区之间切换时自动隐藏其他工作区窗口，并通过一个始终可见的浮动面板完成查看、拖拽和快速切换。

## 作用与功能

- 使用 `Ctrl + Alt + Space` 显示或隐藏工作区面板。
  - 如果系统中已有程序占用了这个热键，应用会自动改用低级键盘钩子监听，避免热键注册失败后完全无响应。
- 默认提供 1 个工作区和“新增工作区”区域；每点击一次新增区域，就在它后面创建一个工作区，最多 9 个。
- 默认工作区不可删除。删除其他工作区前会二次确认，其中的应用不会关闭，而是自动转移到默认工作区；被释放的编号会供之后的新工作区复用。
- 将应用窗口拖到工作区卡片中进行归类，也支持在工作区卡片之间拖拽排序。
- 单击应用条目：切换到对应工作区并把该应用置于前台；如果应用已重启或退出，会先重新绑定窗口，必要时按保存的程序路径启动。右键应用可以打开/置前、移动到指定工作区、移动到显示器或关闭应用。
- 应用标题默认按“应用名 — 内容/项目名”展示，例如 `VS Code — 项目名`、`Google Chrome — 页面标题`；过长内容会截断显示。
- 单个工作区只有一个应用时，双击工作区卡片可以最大化该应用，再次双击恢复原窗口大小；双击应用条目也支持最大化/恢复。
- 工作区卡片支持拖动边缘调整高度；面板本身支持拖动移动，以及从边缘和角落拖拽调整大小。
- 面板默认位于屏幕右上角，使用 Windows 顶层窗口 API 保持置顶且不抢占前台应用焦点；切换工作区后面板仍保持显示。
- 顶部提供“隐藏”按钮；右键面板标题区域可以退出并恢复应用窗口。
- 使用 per-monitor DPI awareness、像素单位字体、ClearType 和统一的 GDI 文本测量/绘制，适配高 DPI 屏幕。
- 顶部提供“全部 / 显示器 N”标签；所有工作区始终展示，选中显示器时只强调该屏幕上的应用。应用按钮的色点标记窗口所在显示器，右键应用可将单个窗口移到另一显示器。
- 点击工作区中的应用时，只最小化同一工作区、同一显示器上的其他应用，另一个显示器的窗口保持原状态；点击工作区卡片时，会切换到该工作区并将其中所有应用最小化。
- 面板使用位置感知的壁纸玻璃渲染：强模糊保留壁纸光影、半透明深色渐变隐藏细节，并在系统壁纸不可读时安全回退；不修改系统壁纸。右键显示器菜单使用独立的圆角玻璃渲染器，固定可读尺寸，并按应用位置和屏幕工作区自动避让。

## 字体模糊与错位的原因

此前看到的“字体模糊、标题和应用列表间距不一致、应用文字重叠”，不是单一字号问题，而是多个渲染因素叠加：

1. 旧实现用 GDI+ `Graphics.DrawString` 绘制文字，同时用 GDI `TextRenderer` 测量文字。两套字体度量不同，导致测量出来的宽高和实际绘制位置不一致。
2. 旧实现使用 `AntiAliasGridFit`，在 Windows 桌面字体场景下容易出现灰边和发虚；截图被缩放后会进一步放大这种感觉。
3. 没有显式启用 per-monitor DPI awareness 时，Windows 可能先按低 DPI 绘制，再对整个窗口做位图缩放，文字和细边框都会变软。
4. 标题和应用列表原来使用固定像素偏移。字号或 DPI 变化后，标题高度变了，但应用列表仍使用旧坐标，因此出现过近、过远或重叠。
5. 旧状态文件可能保存了历史的大面板尺寸。恢复这个尺寸后，卡片数量、间距和按钮区域看起来会被拉伸或挤压。

当前处理方式：

- 启动时启用 Per-Monitor DPI Awareness（优先 Per-Monitor V2，失败时回退到 Per-Monitor）。
- 用 `TextRenderer` 统一测量和绘制，并使用 `ClearTypeGridFit`。
- 统一使用 `Microsoft YaHei UI` 和 `GraphicsUnit.Pixel`，避免 point 字号随缩放产生额外换算。
- 标题与应用行使用同一套动态行高和偏移计算，卡片高度随内容增长。
- 历史面板尺寸超过当前上限时自动迁移到新的右上角默认尺寸。

如果仍然看到模糊，优先检查 Windows 显示缩放、远程桌面缩放和截图软件是否再次缩放了面板；应用本身已经避免对窗口做额外位图缩放。

## 构建

在项目根目录执行：

```powershell
& .\build.ps1 -RunTests
```


脚本会自动编译 Core、WinForms 应用和两组回归测试；不带 `-RunTests` 时只构建应用。

- 面板默认尺寸：`520 × 820`
- 面板最小尺寸：`360 × 360`
- 面板最大宽度：`760px`；高度没有固定上限，实际受当前显示器工作区高度限制
- 面板缩放边缘命中区：`12px`
- 工作区与面板边缘间距：`20px`
- 工作区卡片默认高度：`112px`
- 工作区之间的间距：`12px`

## 已知限制

- 面板是置顶浮动窗口。如果它正好覆盖了底层应用的按钮，覆盖区域内的底层按钮自然无法直接点击；把面板拖开或点击“隐藏”即可操作底层窗口。
- 系统级 `Ctrl + Alt + Space` 若被其他软件占用，应用会使用低级键盘钩子回退，但安全软件可能仍会拦截全局钩子。
- 工作区和面板的尺寸受当前显示器工作区边界约束，不能超过屏幕可用区域。
- 应用窗口若由系统权限更高的进程运行，普通权限的 WorkspaceSwitcher 可能无法控制其显示、隐藏或最大化。
- 点击工作区应用会最小化同工作区其他应用；这些窗口仍保留在任务栏中，可再次点击对应条目恢复。
