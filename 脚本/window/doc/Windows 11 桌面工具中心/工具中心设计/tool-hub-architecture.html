设置中心

模块开关、各模块快捷键、默认保存路径、显示器偏好、启动项与权限状态。

内存策略：工具中心与已启用模块常驻；录屏编码、截图预览和录音设备仅在操作时初始化并释放。
样式策略：组件共享一套 Fluent 色板、圆角、字体与 DPI 文本绘制，不再由每项功能各自定义样式。
Windows 11 策略：可直接使用现代多屏与图形捕获接口，减少旧系统兼容分支。
